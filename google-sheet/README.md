# 📊 نظام تتبع العملاء — Google Sheets CRM

نظام لتنظيم كل العملاء اللي كيتواصلوا معك أو كيطلبوا مشروع عبر فورم الموقع.

> ✅ **النظام مفعّل ومربوط بالموقع منذ 2026-07-04.**
> رابط الـ Web App المنشور محفوظ في `index.html` (المتغير `SHEET_WEBAPP_URL`).
> الخطوات أدناه للمرجع فقط إذا احتجت إعادة التفعيل من الصفر.

## ⚙️ خطوات التفعيل (مرة واحدة فقط — 5 دقائق)

### 1. لصق الكود في الشيت
1. افتح الشيت ديالك: [رابط الشيت](https://docs.google.com/spreadsheets/d/1Xngxzn64JcDHlSCHPa6T-a1Dmt6GWefYGzZ2847omdc/edit)
2. من القائمة: **الإضافات (Extensions) ← Apps Script**
3. امسح أي كود موجود، والصق محتوى الملف `Code.gs` كاملاً
4. اضغط **حفظ** (أيقونة 💾)

### 2. بناء النظام
1. من القائمة العلوية فوق الكود، اختر الدالة **setupCRM**
2. اضغط **تشغيل (Run)** ▶️
3. غادي يطلب منك الإذن أول مرة: **Review permissions ← اختر حسابك ← Advanced ← Go to ... (unsafe) ← Allow**
4. ارجع للشيت — غادي تلقى 3 أوراق جاهزة:
   - **📋 الطلبات** — كل عميل في صف، مع قوائم منسدلة وألوان تلقائية حسب الحالة
   - **📊 لوحة التحكم** — إحصائيات ومداخيل محسوبة أوتوماتيكياً
   - **⚙️ الإعدادات** — لوائح الحالات والمصادر والخدمات

### 3. النشر كـ Web App (باش الفورم يرسل للشيت)
1. في Apps Script: **نشر (Deploy) ← نشر جديد (New deployment)**
2. اضغط ⚙️ بجانب "Select type" واختر **Web app**
3. الإعدادات:
   - **Execute as**: أنا (Me)
   - **Who has access**: أي شخص (**Anyone**) ← مهم جداً!
4. اضغط **Deploy** وانسخ الرابط اللي كيبدا بـ `https://script.google.com/macros/s/...`

### 4. ربط الموقع
- عطيني الرابط اللي نسختيه ونحطو في الموقع، أو بدّلو بنفسك في `index.html`:
  ```js
  const SHEET_WEBAPP_URL = 'الرابط هنا';
  ```

## ✅ كيفاش يخدم النظام

- كل ما يملأ عميل الفورم في الموقع ← يوصل تلقائياً للشيت بحالة **🆕 جديد** ومصدر **🌐 فورم الموقع**، ويفتح الواتساب عادي.
- العملاء اللي كيجيو من الواتساب مباشرة ← زيدهم يدوياً في صف جديد واختر المصدر **💬 واتساب مباشر**.
- بدّل **الحالة** من القائمة المنسدلة ولون الصف كيتبدل بوحدو (جديد → تواصل → اتفاق → تنفيذ → تسليم).
- عمّر **السعر المتفق** و**المدفوع** ← عمود **المتبقي** كيتحسب أوتوماتيكياً، والمجاميع كتبان في لوحة التحكم.

## 🔄 ملاحظات

- إلا بدلتي الكود من بعد، خاصك دير **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** باش التعديل يتفعّل.
- تشغيل `setupCRM` مرة أخرى غادي يمسح بيانات ورقة الطلبات ويعيد بناءها — استعملها غير في البداية.

## 💰 وحدة الماليات (مصاريف + مداخيل + داشبورد احترافي) — v1

> ✅ **إضافية 100%: ما كتمسحش ولا توتوشي بيانات "📋 Commandes" الحقيقية.**
> آمنة تشغّلها فأي وقت، حتى بعد ما يبدا عندك عملاء حقيقيين فالشيت.

### التفعيل (خطوة واحدة)
1. افتح **Extensions ← Apps Script**، امسح الكود القديم، ولصق محتوى `Code.gs` **المحدّث** كاملاً (فيه دابا الكود القديم + وحدة الماليات الجديدة فآخره).
2. احفظ 💾.
3. من القائمة العلوية فوق الكود، اختار الدالة **`setupFinanceSystem`** واضغط **▶️ تشغيل**.
   - أول مرة غادي يطلب إذن إضافي (نفس خطوات "Allow" ديال أول تفعيل).
4. رجّع للشيت — غادي تلقى:
   - **💸 Finances** — ورقة جديدة لتسجيل كل دخول ومصروف حقيقي (تاريخ، نوع Revenu/Dépense، فئة، وصف، مبلغ، طريقة الدفع)، بتلوين تلقائي (أخضر=دخل، أحمر=مصروف).
   - **📊 Tableau de bord** — مُعاد بناؤها بالكامل: 4 بطاقات KPI ملوّنة (إجمالي المداخيل، إجمالي المصاريف، الربح الصافي، هامش الربح %)، جدول حالة المشاريع (كيف كان قبل)، ورسمين بيانيين (Pie chart لتوزيع المصاريف، Column chart للمداخيل مقابل المصاريف شهرياً).
5. من بعد هاد المرة، عندك **قائمة سريعة** فوق فالشيت: **🛠️ أدوات CRM** (كتبان أوتوماتيكياً كل ما تفتح الشيت) — منها تقدر تعاود `setupFinanceSystem` أو `buildDashboard` وحدها بلا ما تدخل لـ Apps Script.

### ⚠️ مهم: وين نسجّل الدخل الحقيقي؟
باش الداشبورد يعطي أرقام صحيحة، **كل فلوس دخلت أو خرجت لازم تتسجل فورقة `💸 Finances`** (بحتى الدفعات ديال العملاء — زيد سطر "Revenu / Projet client" ملي تقبض). عمود "Payé" فـ Commandes خلاصة سريعة للمشروع فحد ذاته، لكن `Finances` هي المصدر الوحيد اللي كيغذي الداشبورد والرسوم البيانية.

### 🔄 التحديثات اللاحقة
- بدّلتي الكود؟ عاود ديبلوي (Deploy ← Manage deployments ← New version) **غير إذا بدّلتي `doPost`/`doGet`** — إضافة وحدة الماليات وحدها ما كتأثرش على الفورم، فما تحتاجش ديبلوي جديد.
- بغيتي تحدّث الداشبورد فقط (بعد ما تزيد فئات مصاريف جديدة مثلاً)؟ شغّل `buildDashboard` من القائمة أو من Apps Script.

### 💸 التحويل التلقائي: Commandes (Livré) → Finances
- ملي تبدّل **الحالة** ديال أي طلب لـ **"✅ Livré"** (وكان عمود **Payé (DH)** معمّر)، القيمة كتتحوّل أوتوماتيكياً لسطر جديد فورقة `💸 Finances` (نوع "Revenu"، فئة "Projet client")، بلا ما دير والو يدوياً.
- كل طلب كيتحوّل **مرة وحدة فقط** (عمود مخفي جديد `Transféré Finance` فآخر Commandes كيمنع التكرار). إلا بدّلتي "Payé" من بعد التسليم، التحويل ما غاديش يتكرر — صحّح المبلغ مباشرة فورقة Finances إلا احتجتي.
- **الطلبات اللي كانت "Livré" من قبل** (قبل ما نزيد هاد الميزة): شغّل مرة وحدة **`backfillFinanceFromCommandes`** (موجودة فقائمة 🛠️ أدوات CRM) باش تجيب الدفعات القديمة لورقة Finances.

### 📅 اختيار التاريخ بالكلندر
- عمود **Date** فورقة `💸 Finances` دابا فيه Data Validation من نوع "تاريخ" — غير دوز عليه بالنقر، غادي يبان أيقونة كلندر صغيرة، اضغط عليها، اختار التاريخ، وتم. ما بقاش داعي تكتب التاريخ يدوياً.
